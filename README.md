# Student Information System (SIS) Database

This project contains the **database design** and **SQL scripts** for a Student Information System (SIS).  
It is designed for **Oracle Database** and includes tables, sequences, triggers, stored procedures, functions, and views.

---

## 📂 Project Structure

The `Student-Information-System-main` folder contains the following SQL files:

- **Tables.sql** → Creates the main database tables (`Students`, `Courses`, `Enrollments`, `Instructors`, etc.).
- **Sequences.sql** → Defines auto-increment sequences for primary keys.
- **Triggers.sql** → Creates triggers for automatic ID generation and consistency checks.
- **Procedures.sql** → Contains stored procedures for database operations.
- **Functions.sql** → Contains reusable functions for calculations (e.g., GPA).
- **Views.sql** → Provides simplified read-only access to combined data.
